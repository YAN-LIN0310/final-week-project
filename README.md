# Speed Run: Neon Labyrinth (極限迷宮生存)

## 1. 專題簡介
這是一款使用原生 JavaScript 與 HTML5 Canvas 開發的 2D 高難度平台遊戲。玩家必須在極限時間內利用梯子攀爬迷宮，避開致命陷阱，抵達頂端終點。

## 2. 特色玩法
* **毫秒計時系統**：大幅增加玩家的急迫感。
* **隨機陷阱系統 (Trap System)**：每個關卡隨機生成死亡按鈕，增加遊戲難度。
* **視覺優化**：霓虹螢光風格，且 UI 儀表板不遮擋遊戲視線。

## 3. 遊戲玩法
* [W / Space] : 跳躍
* [A / D] : 左右移動
* [W / S] : 在梯子上爬行
